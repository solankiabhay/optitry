# OptiTry

OptiTry is an Android virtual eyewear try-on app project.

## Planned features
- Front-camera preview
- Face tracking and glasses overlay
- Eyeglasses and sunglasses catalog
- Import a product image from the gallery
- Capture, save, and share try-on photos

## Status
Project setup is in progress. Live face tracking, the eyewear overlay, and the complete catalog still need implementation and device testing.
